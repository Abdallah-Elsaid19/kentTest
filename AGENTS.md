# Kent Business College project guidance

## Brand patterns

When the user asks to "use the patterns", "use our patterns", or otherwise refers to the KBC decorative patterns, follow `docs/KBC_BRAND_PATTERNS.md` and use the canonical transparent PNG assets in `frontend/public/assets/patterns/`.

Treat the patterns as subtle background watermarks in the style of the approved Applied Learning reference. Do not use them as dominant foreground illustrations unless the user explicitly requests that.
